# Original Mini Devin prototype

This is a preserved copy of the two files from the beginning of this project, before
the Secure Coding Assistant assessment work. `agent.py` contains the original
`write_file`, `read_file`, and `run_file` helpers and the original demonstration code.

The original `sample.py` has an unterminated string, so `python agent.py` shows the
original failure-reporting behavior. `working_sample.py` is a separate valid sample
for experimentation; it does not replace or alter the original. To try it, copy
`working_sample.py` over `sample.py` in your own working copy of this folder.

Run from this folder:

```text
python agent.py
```
